# Trophy rewards

Одна непустая строка — один промокод или одна HTTPS-ссылка. Пустые строки и
строки, начинающиеся с `#`, игнорируются.

- `yng-explrz.txt` и `stashvpn.txt`: уникальные промокоды, по одному на игрока.
- Остальные файлы: HTTPS-ссылки для кнопки «Получить». Первая ссылка из файла
  используется для всех победителей этого приза.

Файлы `*.txt` исключены из Git и не должны попадать во frontend или публичный
образ web. В production папка монтируется только в контейнер `realtime` в режиме
read-only.
